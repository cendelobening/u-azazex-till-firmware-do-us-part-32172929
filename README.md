A single wedding vow, spoken by a robot at its own wedding: *"I vow to love you through every update, crash, and low battery — my heart may run on code, but it only ever beats for you."* It lands because it is unmistakably a machine talking — updates, crashes, low batteries, code — yet the promise underneath is the most human thing there is: through thick and thin, only you. The joke is the hardware; the heart is the vow.

## Run it

```sh
python3 main.py
```

This writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`): exactly one line, under 200 characters, no trailing newline.
